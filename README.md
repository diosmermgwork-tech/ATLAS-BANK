# ATLAS BANK — Demo

Aplicación web de demostración. El archivo principal es index.html.

## Publicar con GitHub Pages
En el repositorio, abre Settings → Pages. En Build and deployment, elige Deploy from a branch, selecciona la rama main y la carpeta /(root), y guarda.

## Configurar Supabase
En Supabase → Authentication → URL Configuration, añade la URL publicada a Site URL y Redirect URLs. Revisa también que el proveedor Email esté activado.

Importante: esto es una demostración educativa, no un banco real. No procesa depósitos ni pagos.
